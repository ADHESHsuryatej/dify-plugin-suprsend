# Privacy Policy

## What this plugin sends

The SuprSend plugin sends the data you give its tools to the SuprSend API (`https://hub.suprsend.com`) so SuprSend can carry out the action. Depending on the tool, this can include:

- user identifiers (distinct ID), names, email addresses and phone numbers
- timezones and custom user properties
- notification preference choices
- workflow names, template data and tenant IDs

Your SuprSend API key is sent only to `hub.suprsend.com`, as an authorization header.

## What this plugin stores

The plugin itself stores, caches and logs nothing. It holds no data between calls, and it sends nothing anywhere other than SuprSend.

## How SuprSend handles the data

Data sent to SuprSend is processed under SuprSend's privacy policy: https://www.suprsend.com/privacy
